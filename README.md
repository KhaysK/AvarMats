# Avar Mats — аварский язык: карточки

Тренажёр слов и фраз по урокам (Дарс 1–5): карточки, выбор перевода, сборка фразы, ввод ответа и «найди ошибку». Слабые слова возвращаются чаще, но не подряд. Прогресс хранится в браузере, ничего устанавливать не нужно.

Открыть: https://khaysk.github.io/AvarMats/
